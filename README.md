# GEORGRAD Point Field

**Сайт:** https://aleger200326.github.io/georgrad-studio/

Самостоятельный редактор анимированного облака точек для браузера. Можно создать сферу, превратить собственный текст или изображение в точки, настроить движение и ракурс, сохранить MP4 или GIF.

## Возможности

- Русский, английский и узбекский интерфейс.
- Тёмная и светлая темы.
- Анимация, эффекты, трек-точки и управление камерой.
- Экспорт в MP4 через WebCodecs и в GIF через gifenc.
- Обработка изображений выполняется локально в браузере.

## Запуск

Это статический сайт без сборки. Откройте `index.html` через локальный веб-сервер. Например, если установлен Python:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## GitHub Pages

1. Загрузите **все** файлы и папку `vendor/` в корень ветки `main`.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, затем **main** и **/ (root)**, нажмите **Save**.
4. После публикации ссылка будет вида `https://aleger200326.github.io/georgrad-studio/`.

MP4 требует браузер с WebCodecs и поддержкой H.264 (например, Chrome или Edge). GIF доступен в большинстве современных браузеров. На телефонах длинный экспорт может занять время.

`mockups/` содержит **иллюстративные концепт-мокапы** для публикации. Они показывают визуальное направление и не являются точными скриншотами интерфейса.
